# Risorse usate nell'analisi

Qui teniamo riferimenti e materiali (wireframe, foto dei disegni su carta,
screenshot di app simili, appunti). **Non salvare foto o dati personali della
bambina**: il repository è pubblico.

- Flutter — internazionalizzazione: https://docs.flutter.dev/ui/accessibility-and-internationalization/internationalization
- Flutter — architettura consigliata: https://docs.flutter.dev/app-architecture
- Riverpod: https://riverpod.dev
