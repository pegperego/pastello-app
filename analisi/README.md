# Analisi (italiano)

Questa cartella raccoglie il lavoro di analisi del progetto, in italiano.
La documentazione per i contributori, in inglese, è in [`../docs/`](../docs/).

| File | Contenuto | Stato |
|---|---|---|
| [`01-analisi-architetturale.md`](01-analisi-architetturale.md) | Vincoli, requisiti non funzionali, decisioni tecniche, rischi | Approvata |
| [`02-analisi-funzionale.md`](02-analisi-funzionale.md) | Utenti, decisioni funzionali, priorità | Approvata |
| [`03-design.md`](03-design.md) | Palette, caratteri, icona, stile grafico | Approvato |
| [`risorse/`](risorse/) | Link, riferimenti, wireframe, foto, materiale usato nell'analisi | In corso |

## Flusso di lavoro

1. Le decisioni si discutono qui, con un codice (`AD-xx`, `D-xx`).
2. Quando una decisione è approvata, si riporta in inglese come ADR in
   `docs/adr/`.
3. I documenti di analisi restano come storico: non vanno aggiornati a ogni
   modifica del codice.
