# Security Policy

## Supported versions

Only the latest released version receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
("Report a vulnerability" button in the *Security* tab of this repository).
If you cannot use it, write to
[pastello.app@proton.me](mailto:pastello.app@proton.me).
We will acknowledge the report as soon as possible and keep you informed about
the fix.

Because this app is used by children, we treat any issue that could expose
data stored on the device or allow content to leave it without an adult's
action as a security vulnerability.
